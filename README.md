# HR_Analytics_Dashboard

📌 **Project Overview**

This project is an HR Analytics Dashboard built using Microsoft Excel to analyze employee data and provide actionable insights into workforce trends, attrition, and demographics. The dashboard helps HR teams and management make data-driven decisions effectively.

🎯 **Key Objectives**

Analyze employee attrition patterns

Track workforce composition

Understand job satisfaction and age trends

Identify department-wise and job-wise attrition

🔑 **Key Metrics Displayed**

Total Employees: 1470

Active Employees: 1233

Attrition Count: 237

Attrition Rate: 16%

Average Age: 37

Job Satisfaction Rating: 3.2

📈 **Dashboard Insights**

Gender-wise analysis

Education-wise attrition

Job role-wise attrition

Department-wise attrition

Age group-wise attrition

Marital status-based attrition

All visuals are interactive and designed for quick interpretation.

🛠 **Tools & Techniques Used**

Microsoft Excel

Pivot Tables & Pivot Charts

Excel Slicers

Data Cleaning & Formatting

Dashboard Design & Layout

▶️ **How to Use**

Download the file: HR_Analytics_Dashboard.xlsx

Open it using Microsoft Excel (2016 or later recommended)

Use the slicers (Gender, Department, Education, Job Role) to filter data

Analyze KPIs and charts that update dynamically based on selections
